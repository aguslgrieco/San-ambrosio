Nuestra filosofía institucional

Todo lo que enseñamos se sostiene sobre estas tres columnas.

Pensamiento efectivo

Herramientas concretas para razonar, decidir y resolver problemas reales, dentro y fuera del aula.

Inteligencias múltiples

Reconocemos distintas formas de ser inteligente y diseñamos propuestas que las potencian a todas.

Enseñanza para la comprensión

Se enseña para comprender, no para repetir: cada contenido se aplica, se explica y se transfiere.

Valor 01

Empatía

Escuchamos antes de enseñar. Cada estudiante llega con una historia que el aula respeta.

Valor 02

Colaboración

Se aprende mejor en conjunto: el trabajo en equipo es parte del contenido, no un extra.

Valor 03

Respeto

Las diferencias se entienden como punto de partida, no como obstáculo para convivir.
